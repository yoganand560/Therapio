## ❓ FAQ

### Q: Do I need to set up Firebase?
**A:** No! The new system works without any setup.

### Q: Which files should I use?
**A:** Use files ending with `-new.html` (login-new.html, dashboard-new.html, ai-assistant-new.html)

### Q: Where is my data stored?
**A:** In your browser's localStorage. It persists across sessions.

### Q: Is this production-ready?
**A:** It's perfect for demos, prototypes, and learning. For production with real users, you'd want to add a backend server.

### Q: Can I use real Google/Microsoft login?
**A:** Current version simulates social login. For real OAuth, you'd need Firebase or Auth0 setup.
